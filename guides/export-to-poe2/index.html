From your browser to the game

  1. Plan your passive tree

    Open the PoE 2 passive-tree planner, choose your class and optional ascendancy, and allocate your passives. Select an unallocated node to preview its path, then select it again to commit.

    On a phone, tap the menu button in the top-left corner to open the toolbar. If you use separate weapon-set paths, enable Weapon Sets and plan them with Main, Set 1, and Set 2.

  2. Choose “Export to PoE 2”

    In the toolbar, select Export to PoE 2. You need at least one allocated passive before you can download a build.

  3. Name and download your build

    Enter a name you will recognize in-game, then choose Download build. Save the .build file to Files or Downloads on your device. Keep its file extension as .build.

  4. Upload the file to your GGG account

    Select Open GGG upload page in the export dialog, or open the official upload page ↗. Sign in to the account you use to play, select the file you downloaded, and upload it. Follow the website’s prompts to make the build available to your account.

    You can do this from your phone’s browser; choose the saved file from Files or Downloads.

  5. Select the guide in the in-game Build Planner

    Open Path of Exile 2 and select your uploaded guide in the game’s Build Planner. Use it to follow your planned passive tree. You still spend your points and choose attribute bonuses in-game.

What does the export include?

This planner exports the passive-tree portion of a build:

  • Your allocated shared passives and both weapon-set branches.
  • Your selected ascendancy and its allocated passives, when chosen.
  • Recommendations for attribute bonuses you explicitly selected. Unspecified nodes have no recommendation.
  • The build name and a link back to your planned tree.

Gear, skill gems, support gems, and leveling stages are not included. Download a new file and upload it again when you want to take later edits into the game.

Alternative for Windows players

Use a local BuildPlanner folder

If you play on Windows, you can place your downloaded .build file in the game’s local BuildPlanner folder instead of uploading it:

C:/Users/Name/Documents/My Games/Path of Exile 2/BuildPlanner

Replace Name with your Windows user folder. This is GGG’s documented default location; your Documents folder may be somewhere else, for example under OneDrive.

GGG says the game detects changes in this folder. See the official Build Planner documentation for file locations and the account-based alternative.

Troubleshooting your export

Why is “Download build” disabled?

Allocate at least one passive and enter a build name that is not blank. If an error appears after downloading is attempted, follow its message and try again.

Where is the file on my phone?

Check your browser’s downloads list and your Files or Downloads app. Save the file to your device before selecting it on GGG’s upload page. The filename ends in .build and includes the tree version.

Does a Share link work as an in-game import?

The Share button creates a link that opens your tree in this website. To use the tree in-game, choose Export to PoE 2 and download the .build file.

Why can’t I find the guide in-game?

Check that you uploaded the file to the account you use to play and completed the website’s prompts. For a local Windows import, check the folder and confirm the file ends in .build, rather than .build.txt. Use a tree version that matches the game you are playing.
